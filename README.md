# Platformer Prototype – Rolling Physics

**Engine:** Godot  
**Language:** GDScript  
**Project Type:** Gameplay Prototype  

## Overview

This project is a small platformer prototype built to experiment with momentum-based movement and rolling physics inspired by characters such as Sonic the Hedgehog and Donkey Kong.

The focus of the project was exploring how rolling mechanics, slopes, and momentum preservation affect platforming feel and player control.

## Gameplay Features

- 2D platformer movement system
- Rolling mechanic that builds and preserves momentum
- Rolling dash ability
- Momentum preserved when jumping out of a roll
- Rolling acceleration when moving down slopes
- Basic platforming environment for testing movement systems

## Systems Implemented

### Player Controller
Platformer movement controller supporting running, jumping, and rolling mechanics.

### Rolling Physics
Rolling system that allows the player to gain speed and preserve momentum across actions such as jumping.

### Slope Interaction
Slope handling that affects player speed, allowing acceleration when rolling downhill.

## Development Goals

- Experiment with momentum-based platformer movement
- Explore how rolling mechanics influence game feel
- Practice implementing physics-based gameplay systems
- Prototype responsive and satisfying character movement

## What I Learned

Through this prototype I explored how momentum, slopes, and movement states interact to create satisfying platforming mechanics.  
The project also helped me experiment with structuring movement systems and tuning parameters to improve overall game feel.
